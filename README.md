## 机房IP、住宅IP、双ISP，差的到底是什么

先把三个词拆开。

机房IP的注册主体是数据中心，无论你把它包装成哪个国家，平台反查ASN就能看到云厂商的名字。TikTok对这类IP的处理是降权限流，BBC iPlayer的处理更直接——弹“内容不可用”。这也是为什么市面上二三十块一个月的“英国VPS”看起来配置不差，拿去跑英国本土业务却几乎必然失败。

住宅IP的注册主体是本地宽带运营商，和普通家庭宽带的出口在平台眼里属于同一类。双ISP再进一步：这个IP同时注册在两家本土运营商名下，纯净度更高，也更不容易被历史风控名单连带标记。有测评用一句话概括得挺准——从平台视角看，这就是一个普通的英国家庭用户在上网。

丽萨这台机器的落点是伦敦，接入的是Sky天空电讯（Sky Telecom）这类英国本地宽带运营商的IP段，属全新A段、双ISP原生住宅属性。全新A段这点值得单独说：老IP段被反复倒手，黑名单命中率高；新段的历史记录干净，起号阶段的通过率通常更好。需要提醒的是，IP纯净不等于永久免疫，平台风控是动态的，这点后面FAQ里再讲。
